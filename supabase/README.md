# Supabase

1. Create a project at https://supabase.com  
2. Run `migrations/20261113000000_init_schema.sql` in the SQL editor  
3. Run `seed.sql` to load bootstrap marketplace rows (moved out of the Flutter app)  
4. Set `DATABASE_URL` in `.env` to the project connection string  
5. Start the API and Flutter client — see `docs/database/SUPABASE.md`
